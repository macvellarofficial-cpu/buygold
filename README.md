# BUYGOLD — Official Corporate Website & Investment Platform

Official corporate website for **BUYGOLD Investments Limited**, engineered for high reliability, performance, and responsive elegance. Designed for hosting at [www.buygold.blog](https://www.buygold.blog).

---

## 🌟 Key Features

- **High-Fidelity Multi-Page Experience**:
  - `index.html` — Homepage with interactive hero, feature showcases, core values, 4-step workflow pipeline, and consultation booking form.
  - `about-us.html` — Corporate history, mission, core values, animated expertise metrics, and projects showcase.
  - `mining.html` — Comprehensive gold mining operations, equipment standards, and direct contact desk.
  - `agri-business.html` — Agricultural transformation, food security initiatives, and sustainable farming solutions.
  - `supply-and-logistics.html` — Multimodal freight forwarding, warehousing, and customs clearance solutions.
  - `engineering.html` — Infrastructure design, civil works, mechanical engineering, and project management.
  - `contact-us.html` — Interactive multi-field contact desk with instant feedback notifications.
  - `disclaimer.html` — Public fraud warning and verified corporate channels notice.
- **Custom Brand Identity**:
  - Luxury 3D bullion and growth arrow vector logo (`assets/images/buygold_logo.svg`).
  - High-contrast dark mode vector logo for drawer navigation (`assets/images/buygold_logo_light.svg`).
  - Crisp favicon icon (`assets/images/buygold_icon.svg`).
- **Interactive Capabilities**:
  - Circular SVG progress fill scroll-to-top indicator.
  - Offcanvas slide-in navigation drawer.
  - Mobile responsive hamburger menu.
  - Animated toast notifications on form submissions.
- **Zero External Runtime Dependencies**:
  - 100% self-hosted images and assets in `assets/images/`.
  - Built-in zero-dependency Node.js HTTP server supporting clean extensionless URLs.

---

## 🚀 Quick Start

### 1. Prerequisites
- [Node.js](https://nodejs.org/) (version 16 or newer recommended)

### 2. Running Locally
```bash
# Start the local server
npm start
# or
node server.js
```

Open your browser and navigate to:
```
http://localhost:3000
```
